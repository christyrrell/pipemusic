The Ceol Sean Master Index

                       

Stream at the Edradour Distillery

Welcome to the Ceol Sean Master Index! This page is your entry way to links for over 6,800 tune settings. But first, please be sure that you have familiarized yourself with the Navigation Tips.

To link to a tune setting, click on the appropriate link for the first letter in the name of the tune from the "sub index" page links shown below (and keep in mind the way tune names are alphabetized as described in the Navigation Tips.) You will link to a "sub index" page that has an alphabetical listing of links to the tune settings. From there, simply scroll through the list to find the link to the desired setting.

If you want to search a complete list of tune settings, we recommend you use the PDF version of the Master Index. When using this PDF index, you should note that there is a link to the Master Index Page at the top of the first page. (In case you are wondering, we tried working with single list of all tunes with links, but the file size was too large to be workable.) Please keep in mind that the Master Index links are for tune settings only. Links to other items contained in the tune collections (such as tutors, MacKay's account of the history of the competitions, Fionn's Notes in David Glen's piobaireachd, etc.) are found only on the individual collection pages.

The "return to index" link found in the upper corner of the individual tune setting files will link you to this page. Otherwise, you will need to use your back button to return to the "sub index" page having the link you followed.

We hope you enjoy your tune search!!
